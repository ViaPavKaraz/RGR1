Опис проєкту
Даний репозиторій містить реалізацію РГР №1, присвячену аналізу математичних функцій та їх диференціюванню. Проєкт демонструє застосування принципів ООП, рефакторингу та використання зовнішніх бібліотек для математичних обчислень і візуалізації.

Основні можливості:
1.Обчислення функцій: підтримка аналітичного (формула) та табличного (точки) способів завдання.
2.Диференціювання: реалізовано чисельний метод (скінченні різниці) та символьний метод (через JCM).
3.Колекції: використання ArrayList, TreeMap та TreeSet для оптимізації роботи з табличними даними.
4.GUI: графічний інтерфейс на Swing для введення формул та налаштування параметрів.
5.Візуалізація: побудова динамічних графіків за допомогою JFreeChart.

Структура репозиторію
1.src/ — вихідний код програми (.java файли).
2..git/ — історія комітів (версіонування).
3.README.md — опис проєкту.
4..gitignore — конфігурація для ігнорування бінарних файлів (out, bin, .class).

Інструкція з налаштування
Для коректної роботи проєкту необхідно підключити наступні зовнішні бібліотеки (.jar файли):
1.JFreeChart (jfreechart-1.x.x.jar, jcommon-1.x.x.jar) — для побудови графіків.
2.JCM (Java Components for Mathematics) — для парсингу математичних виразів та символьного диференціювання.

Як запустити:
1.Відкрийте проєкт у середовищі IntelliJ IDEA.
2.Додайте вказані JAR-бібліотеки до структури проєкту.
3.Запустіть клас Main.java.
